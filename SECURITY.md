# Security

Report suspected vulnerabilities privately through this repository's GitHub
Security Advisories when available. Otherwise contact the maintainer without
including credentials, bond keys, raw remote captures or personal logs in a
public issue. Supported fixes target the latest tagged release.

This is a home-automation bridge, not a trusted security boundary against a
compromised Docker host or malicious radio/decoder. See docs/security.md for
privileges, LAN trust, failure behavior and backup handling. Do not use it for
locks, alarms, life-safety equipment or security-critical actions.
